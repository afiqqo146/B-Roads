---
name: new-lead
description: Leads Team playbook. Turns a pasted enquiry (WhatsApp, email, web form, call notes) into a customer card, scores it, matches stock and drafts the reply. Use when the user pastes or dictates a new enquiry.
---

1. **lead-catcher** first, alone: create or update the customer card from the enquiry. Note the card's file name.
2. Then, **at the same time**, give each the card file name:
   - **lead-qualifier**: score and next questions.
   - **stock-matcher**: top 3 cars from stock.
   - **trade-in-estimator**: only if the card mentions a trade-in.
3. Then **follow-up-writer**: draft the reply using the score, the matches and the open questions.
4. **board-keeper**: add the lead to the board (HOT leads go to the top of Doing).

Reply: customer name, score and why, top match, and "Reply drafted in the outbox. /approve to check it."
